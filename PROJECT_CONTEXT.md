# PROJECT CONTEXT

## Product Vision

Mission Control is the central dashboard and management platform for process, task, goal, team, and revenue tracking in Pete's organization. It aims to provide a unified view and control panel for active projects, supporting Pete’s directives to deliver autonomous, scalable businesses.

## Current Features

- Project and task listing with status tracking
- Revenue and analytics reporting
- User and team management
- Calendar and scheduling tools
- Message posting and notification integration

## Unfinished Features

- Enhanced offline resilience
- More tab functional features
- Logbook tab inner toggle polish
- Expanded marketing automation funnels

## UI/UX Expectations

- Responsive and mobile-friendly layout
- Clean, data-driven dashboards
- Easy navigation with consistent tabs
- Prominent calls to action on key funnels

## Architecture Notes

- Built on Next.js 16.2 with React 19.2
- Tailwind CSS for styling
- Zustand for state management
- Modular structure with API routes

## Important Assumptions

- Pete will prioritize revenue streams and marketing funnels
- Team members will use GitHub + OpenClaw agents for development
- Deployment hosted primarily on Cloudflare Pages

## What Claude Should Know

- Preserve core funnel and task logic
- Do not delete working existing features without reason
- Use branches and PRs for major changes
- Update this file with changes in architecture or UX
- Focus on upstreaming marketing and revenue improvements
